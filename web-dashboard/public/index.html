Distributed Architecture Status & Deployment Options

The platform supports Dual-Engine Architecture:

  • Mode 1 (Active): Native High-Performance In-Memory Stream Core: Runs with zero dependencies directly on Node.js v24. Processes 9,077 transactions with sub-millisecond CEP evaluation, real-time SSE broadcast, graph indexing, and case management.
  • Mode 2: Distributed Production Cluster (Docker Compose): Integrates Apache Kafka (KRaft), Apache Flink 1.17, and ClickHouse 23.8. To activate, ensure Docker Desktop is running and execute: docker compose -f docker/docker-compose.yml up -d.
